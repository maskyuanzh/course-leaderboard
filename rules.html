评测规则

从零训练

本实训使用 OLMo 2 1B 的模型结构与课程 tokenizer。训练从随机初始化开始。

提交日志、权重和推理脚本

在「提交日志」选择 TXT 并校验。日志开头用 Title 写核心改动，用 Description 写做法，正文保留源码、nvidia-smi 和每步 train_loss。文件名用英文小写、数字及连字符，沿用基线的段写 base。

从课程发放的公共目录开始，按 submissions/<队伍>/<运行编号>/ 放置文件。模型目录应含 config.json、tokenizer 文件和完整的 safetensors 权重。

submissions/team-a/run-001/
  team-a__model-base__data-base__params-base__run-001.txt
  submission.json
  model/
  infer.py

日志通过后，在网页填权重目录和推理脚本的实际相对路径，下载 submission.json 放进去。每队交一个最终版本。

推理脚本接受 --model-dir 和 --prompt。上面的例子从运行目录执行以下命令。可以使用这份参考脚本。

python infer.py --model-dir model --prompt "Hello"

查看成绩

课程组收件后，在固定盲测集上统一评测。成绩发布后，榜单按 Test Loss 从低到高更新，同分并列。
